# Leon Agency Website

صفحة ويب تعريفية لوكالة تصميم، مبنية بـ HTML و CSS.

## شرح الكود
الصفحة مقسمة إلى أقسام، وكل قسم مسبوق بتعليق (comment) يوضح بدايته ونهايته:

| القسم | الوصف |
|---|---|
| **Header** | الشعار وقائمة التنقل (features, services, portfolio, about) |
| **Landing** | القسم الترحيبي مع عنوان "Hello There!" |
| **Features** | ثلاث ميزات: Tell Us Your Idea, We Will Do All The Work, Your Product Is Worldwide |
| **Services** | الخدمات: Graphic Design, UI & UX, Web Design, Web Development |
| **Portfolio** | ثلاث بطاقات لعرض المشاريع |
| **About** | نبذة عن الوكالة مع صورة ونصوص تعريفية |
| **Contact** | البريد الإلكتروني وأيقونات التواصل الاجتماعي |

## بنية المشروع
- `index.html` الصفحة الرئيسية
- `css/` ملفات التنسيق
- `images/` الصور
- `webfonts/` خطوط وأيقونات Font Awesome

## التقنيات
HTML5, CSS3, Font Awesome
